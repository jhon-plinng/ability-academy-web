# Ability Academy · Vista previa web

Versión HTML estática de la nueva web de **Ability Academy**, para revisión del cliente.

Páginas: Inicio · Máster Práctico · Mentoría · Otras formaciones · Staff · Webinar · Contacto · Blog.

- Construida en WordPress + Elementor y exportada a HTML con todas las animaciones (GSAP, ScrollTrigger, SplitText y Lenis).
- El formulario del Webinar funciona en **modo demo**: en la web WordPress final, cada registro se guarda y llega por email.
- Pendiente de recibir del cliente: el logo definitivo y los vídeos de presentación del CEO. Ahora mismo hay contenido provisional en esos huecos.
